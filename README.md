# STF Group - Sistema Integral de Trazabilidad de Colchas & Control SLA

Sistema integral desarrollado para **STF GROUP S.A. (Studio F, ELA, Studio F Man)** para la trazabilidad en tiempo real, auditoría de calidad, control de tiempos SLA (>3 días) y sincronización con Google Sheets y Google Drive.

## 🚀 Características Principales

- **Central de Alertas SLA (>3 Días)**: Monitoreo en tiempo real de desviaciones operativas en planta, pre-solicitud, corte, lavandería y calidad.
- **Sincronización Bidireccional con Google Sheets**: Alimentación en tiempo real de la base de datos maestra y la pestaña ALERTAS (14 columnas estructuradas).
- **Asistente de Voz con Inteligencia Artificial**: Botón flotante interactivo con comandos de voz en lenguaje natural para búsqueda de OPs y navegación inteligente.
- **Directorio de Usuarios STF Group (22 Perfiles)**: Notificación selectiva y masiva por correo electrónico institucional.
- **Impresión Térmica Zebra (100mm x 100mm)**: Generación instantánea de etiquetas técnicas con código QR de trazabilidad.
- **Panel de Estadísticas & Comités**: Gráficas de rendimiento mensual, dictamen de calidad (Aprobados vs Rechazados) e indicadores de productividad.
- **Chat STF Teams en Vivo**: Canal de comunicación interno entre inspectores, auditoría y operarios de planta.

## 🛠️ Tecnologías

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Integraciones**: Google Sheets API / Google Apps Script, Google Drive
- **PDF & Impresión**: jsPDF, XLSX, Canvas
- **Estilos**: Modo Claro / Modo Oscuro con diseño corporativo STF Group
